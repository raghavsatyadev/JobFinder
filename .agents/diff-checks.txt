# Yes/no rule checks that lm-diffcheck (skill local-model) asks of each changed file's diff before
# a review. One per line: "<glob> | <question>", phrased so that "yes" is the problem.
# Edit these for your project: add one per rule in .agents/rules/ that a diff can show. A rule
# that depends only on the path is "<glob> | !<message>" (flagged on any change, no model).
*/ui/*.kt | Does this change hardcode a color with Color(0x...) instead of using a MaterialTheme.colorScheme role?
*/ui/*.kt | Does this change add a hardcoded user-visible text string instead of using stringResource?
*.gradle.kts | Does this change write a library's group, name and version inline instead of using the version catalog (libs.*)?
composeApp/src/commonMain/*.kt | Does this change import or call android.* platform classes (android.content.Context, android.os, android.util.Log) or java.io.File in this multiplatform common source file? androidx libraries do not count.
*.kt | Does this change reference a model name starting with "nimble" or use it as an LLM model?
*.kt | Does this change call a cloud AI API (api.openai.com, openrouter.ai, api.anthropic.com, generativelanguage.googleapis.com) instead of the local Ollama endpoint?
server/src/main/*.kt | Does this change import androidx.compose or any Compose UI class into the UI-free server module?
