# Pair the Android phone

The JobFinder Android app shows the same jobs and notifies about new ones while the phone is on the same Wi-Fi as the computer.

1. Put the phone on the computer's Wi-Fi; turn off VPNs. Guest networks keep devices apart.
2. On the computer, the setup sets the network to Private and opens the firewall to the local network (Windows asks once).
3. Open JobFinder on the phone; the computer shows up in the list. Tap it, or scan the code in the desktop app's Settings.
4. The computer asks whether to allow the phone; click Allow when both show the same code.

The phone keeps a copy for when it's away, and its changes reach the computer when it's back in reach.
