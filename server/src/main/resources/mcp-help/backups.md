# Backups and moving computers

Settings → Backup and move → Export everything saves one locked file with searches, jobs, notes, ATS reviews, settings and, on the computer, the online API keys. With a password it opens on any computer or phone; without one, only this device can open it. The computer also saves a locked backup every day.

To move: install JobFinder on the new computer, finish setup, then Import a backup → type the password → Replace everything. Sign in to the job boards again and pair the phone again: sign-ins and pairing codes are never in backups.
