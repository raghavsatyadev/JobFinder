# Browser extension (JobFinder Helper)

Optional, for Chrome or Edge. It shows the ATS score on saved jobs, fills application forms when the user presses Autofill (it never submits), drafts answers with AI, reads pages the app can't open, and can copy the user's job board sign-ins to the app.

Install: in the app's Setup press "Open the extension folder", then open `chrome://extensions` (or `edge://extensions`), turn on Developer mode, choose Load unpacked and pick that folder.
