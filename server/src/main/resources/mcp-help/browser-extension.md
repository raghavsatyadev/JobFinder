# Browser extension (JobFinder Helper)

Optional, for Chrome or Edge. It shows the ATS score on saved jobs, fills application forms when the user presses Autofill (it never submits), drafts answers with AI, reads pages the app can't open, and can copy the user's job board sign-ins to the app.

Install: in the app's Setup press "Open the extension folder". To add it to JobFinder's own browser (the profile the user signs in to job sites with), press "Open JobFinder's browser", which copies `chrome://extensions` (or `edge://extensions`) to paste into its address bar; otherwise open that page in the everyday browser. Then turn on Developer mode, choose Load unpacked and pick that folder.
